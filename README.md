# Elo Solidário — Plataforma web para ONGs

Projeto acadêmico demonstrativo de uma ONG fictícia. O site apresenta informações institucionais, projetos sociais, voluntariado, formas ilustrativas de doação e um formulário de cadastro com validação nativa e máscaras em JavaScript.

## Estrutura de pastas

```text
/
├── index.html
├── projetos.html
├── cadastro.html
├── css/
│   └── style.css
├── js/
│   └── mascaras.js
└── img/
    ├── arquivos .jpg, .png, .webp e .svg das ilustrações
```

## Recursos implementados

- Três páginas HTML5 com estrutura semântica e navegação consistente.
- Layout responsivo mobile-first, com breakpoints em 600 px e 960 px.
- Formulário com nome, e-mail, CPF, telefone, nascimento, endereço, CEP, cidade, estado e perfil de participação.
- Validação nativa por atributos HTML5 e máscaras para CPF, telefone e CEP.
- Cálculo dinâmico da data máxima de nascimento para 18 anos completos.
- Mensagem de retorno demonstrativa no formulário. **Os dados não são enviados nem armazenados**, pois não existe back-end conectado.
- Acessibilidade básica: link para pular ao conteúdo, foco visível, labels, textos alternativos e regiões de status.
- SEO básico: idioma `pt-BR`, `title` e `meta description` em cada página.
- Imagens ilustrativas em JPG, PNG, WebP e SVG.

## Como visualizar

Abra `index.html` no navegador. Para publicar, envie a estrutura completa ao GitHub e configure GitHub Pages em **Settings → Pages**.

## Validação HTML

Valide separadamente `index.html`, `projetos.html` e `cadastro.html` em https://validator.w3.org/ antes da entrega. A criação deste projeto não substitui a validação oficial do W3C.

## Importante

O Elo Solidário, os contatos, os números de impacto e os dados de doação são fictícios e usados apenas para demonstração. Não use dados pessoais reais no formulário. Doações e cadastros reais exigiriam infraestrutura segura, back-end e integração apropriada.
